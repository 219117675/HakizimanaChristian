        <h2>Introduction</h2>

        <p>
            The Agile Logbook records the team's development activities
            throughout the FundiShop project. It provides a record of
            sprint planning, daily progress, challenges, decisions and
            lessons learned during development.
        </p>

        <p>
            FundiShop is a service marketplace that connects homeowners
            with local service providers, known as Fundis. The project
            involves developing a web application with a React frontend,
            a Spring Boot backend and a MySQL database.
        </p>

        <p>
            The logbook helps the team monitor progress, communicate
            problems, identify blockers and reflect on how the development
            process can be improved. It also provides evidence of individual
            and team participation in Agile activities.
        </p>
    </section>

    <section>
        <h2>Sprint Planning Record</h2>

        <p>
            Sprint planning is used to agree on the sprint goal and select
            product backlog items that the team believes it can complete
            within the sprint. The selected items are broken down into
            smaller tasks and assigned according to the team's capacity
            and responsibilities.
        </p>

        <h3>Proposed Sprint Goal</h3>

        <p>
            Develop and improve the main FundiShop user workflow, including
            account access, Fundi discovery and the ability for homeowners
            to request and view bookings.
        </p>

        <h3>Planning Activities</h3>

        <ul>
            <li>Review the prioritised product backlog.</li>
            <li>Discuss the requirements for the selected user stories.</li>
            <li>Identify dependencies and technical requirements.</li>
            <li>Break larger stories into smaller development tasks.</li>
            <li>Allocate responsibilities to team members.</li>
            <li>Agree on the sprint goal and expected outcomes.</li>
        </ul>
    </section>

    <section>
        <h2>Development Progress and Challenges</h2>

        <p>
            During the development of FundiShop, the frontend and backend
            components need to work together to support the main marketplace
            features. This requires communication between the React
            application, Spring Boot REST APIs and MySQL database.
        </p>

        <h3>Technical Areas</h3>

        <ul>
            <li>Developing and improving the React user interfaces.</li>
            <li>Implementing backend endpoints using Spring Boot.</li>
            <li>Connecting application features to the MySQL database.</li>
            <li>Testing user registration and login functionality.</li>
            <li>Implementing Fundi profiles and booking operations.</li>
            <li>Testing communication between frontend and backend.</li>
        </ul>

        <h3>Example Technical Challenges</h3>

        <p>
            One possible integration challenge is ensuring that frontend
            requests can communicate correctly with the backend. For
            example, incorrect API endpoints, CORS configuration or
            unexpected response formats can prevent features from
            working as expected.
        </p>

        <p>
            Another important area is ensuring that booking information
            is correctly associated with the homeowner and the selected
            Fundi. This requires correct backend relationships and
            database operations.
        </p>
    </section>

    <section>
        <h2>Sprint Retrospective</h2>

        <p>
            A sprint retrospective gives the team an opportunity to
            reflect on its working process and identify improvements
            for future sprints.
        </p>

        <h3>What Went Well?</h3>

        <ul>
            <li>Team members had defined responsibilities.</li>
            <li>The backlog provided a structure for organising work.</li>
            <li>Breaking features into smaller tasks helped make development manageable.</li>
            <li>Communication helped the team identify development issues.</li>
        </ul>

        <h3>What Could Be Improved?</h3>

        <ul>
            <li>Improve task estimation before committing to sprint work.</li>
            <li>Communicate blockers as soon as they appear.</li>
            <li>Allow sufficient time for frontend and backend integration.</li>
            <li>Keep Trello cards updated as tasks progress.</li>
            <li>Define clearer acceptance criteria before implementation begins.</li>
        </ul>

    <section>
        <h2>Personal Reflection</h2>

        <p>
            Maintaining an Agile logbook has helped me understand the
            importance of tracking development activities and reflecting
            on progress throughout a software project. It provides a
            structured way to record what the team is working on, the
            problems encountered and the decisions made during development.
            It also helps connect daily tasks with the larger sprint goal.
        </p>

        <p>
            The development of FundiShop involves different components,
            including the React frontend, Spring Boot backend and MySQL
            database. Working across these areas requires coordination
            and regular communication. A feature may be implemented
            successfully in one component but still require additional
            work before it functions correctly as part of the complete
            application.
        </p>

        <p>
            One important lesson is that technical challenges should
            be communicated early. Problems involving API communication,
            database relationships or frontend integration can affect
            other tasks if they are not identified in time. Regular
            progress discussions and updates to the task board can help
            the team identify these issues and decide how to address them.
        </p>

        <p>
            As a backend developer, I have learned the importance of
            designing and testing backend functionality with the frontend
            requirements in mind. Backend endpoints must return the
            information expected by the user interface, while database
            relationships must correctly represent the application's
            data. This has strengthened my understanding of API
            development, integration and software testing.
        </p>

        <p>
            For future sprints, I would improve task estimation, clarify
            requirements before implementation and allocate more time
            for testing and integration. I would also make sure that
            progress and blockers are recorded consistently. These
            improvements can help the team work more efficiently and
            deliver a more reliable FundiShop application.
        </p>
